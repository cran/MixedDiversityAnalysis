
# MixedTraitAnalysis 0.1.0

## Initial development release

- Added `mixed_distance()` for custom mixed-trait dissimilarity calculations.
- Added `mixed_cluster()` for hierarchical clustering and silhouette-based selection of the number of clusters.
- Added `mixed_pcoa()` for Principal Coordinates Analysis.
- Added `mixed_trait()` for descriptive trait-separation scores.
- Added `mixed_visualize()` for dendrogram, silhouette, PCoA, and trait-separation plots.
